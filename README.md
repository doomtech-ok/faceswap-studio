# FaceSwap Studio

Build a web tool for local video face swapping. The interface should include:

An upload area for "Source Face" (accepting images).

An upload area for "Target Video" (accepting short mp4/webm videos).

A "Start Face Swap" button.

A video player area to display results.
Please keep the design simple, dark theme. Do not include any backend logic or database yet.
